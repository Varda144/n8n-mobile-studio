# N8N Mobile Studio

A complete mobile-first workflow automation editor built with Flutter.

## Features

- **Visual Workflow Editor** - Canvas-based node editor with drag & drop
- **Multi-Instance** - Connect to multiple n8n instances
- **AI Assistant** - Generate, explain, fix, optimize, and debug workflows
- **MCP Integration** - Connect to Model Context Protocol servers
- **Executions** - Monitor and debug workflow runs
- **Webhooks** - Manage webhook endpoints
- **Credentials** - Secure credential management
- **Templates** - Pre-built workflow templates
- **Offline Cache** - Work offline with local storage
- **Dark Mode** - OLED-optimized dark theme

## Design System

- **Theme**: OLED Dark Mode with true black (#020617)
- **Accent**: Running green (#16A34A) for success/active states
- **Typography**: Fira Sans / Fira Code
- **Effects**: Subtle glow, dark-to-light transitions

## Build APK

GitHub Actions automatically builds the APK on push to main.

1. Go to **Actions** tab
2. Click **Build Flutter APK**
3. Download from **Artifacts**

## Tech Stack

- Flutter 3.24
- Provider (State Management)
- GoRouter (Navigation)
- Custom Canvas (Workflow Editor)
